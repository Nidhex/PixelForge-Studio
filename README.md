## 🎨 Visual Identity & Design Philosophy

Inspired by high-end independent creative studios, European art-directed agencies, and contemporary editorial design:

- **Less Boxes, More Whitespace**: Clean horizontal hairline dividers instead of claustrophobic card containers.
- **Bold Editorial Typography**: Oversized geometric grotesque headlines paired with monospace numerals and generous tracking.
- **Controlled Palette**:
  - `Lime` (**#DCEB78**): Vibrant background for key hero, contact, and recommended package accents.
  - `Near Black` (**#171717**): High-contrast typography, dark sections, and tactile action buttons.
  - `Warm White` (**#F2F0E8**): Soft natural surfaces and high-contrast editorial breathing room.
- **Fluid Micro-Interactions**: Subtle Framer Motion animations that respect `prefers-reduced-motion` settings.

## 📁 Project Architecture

The codebase has been consolidated into a minimal, clean, and easily maintainable structure:

```
developersWeb/
├── .vscode/
│   └── settings.json        # Tailwind CSS language settings
├── dist/                    # Optimized production bundle
├── public/                  # Static public assets
├── src/
│   ├── assets/              # Logos and graphics
│   ├── App.jsx              # Consolidated single-file component architecture
│   ├── App.css              # App-level styles
│   ├── index.css            # Base Tailwind imports & scrollbar styles
│   └── main.jsx             # React DOM entry point
├── index.html               # HTML5 shell with Google Fonts & favicon
├── package.json             # Scripts & dependency definitions
├── tailwind.config.js       # Color tokens & typography configuration
└── vite.config.js           # Vite build pipeline
```

## 💻 Local Development Setup

To run PixelForge Studio locally on your computer:

### 1. Clone the repository
```bash
git clone https://github.com/your-username/pixelforge-studio.git
cd pixelforge-studio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start local development server
```bash
npm run dev
```
Open [http://localhost:5173/](http://localhost:5173/) in your browser to view the application with Hot Module Replacement (HMR).

### 4. Create production build
```bash
npm run build
```

### 5. Preview production build locally
```bash
npm run preview
```
